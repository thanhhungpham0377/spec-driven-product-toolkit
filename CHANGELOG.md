# Changelog

All notable changes to this toolkit are documented here.

## 1.1.0 - 2026-09-26

### Added

- Capability-based component registry and profile files.
- Compatibility/conflict preflight.
- Manifest upgrade and rollback helpers.
- Provenance and migration documentation.

### Compatibility

- Existing `prototype`, `balanced`, and `production` profile names remain supported.
- Existing generated `.spec-product/manifest.json` files can be upgraded in place.

## 1.0.0

- Initial three-profile installer and source catalog.
